# Universal Printing Package Documentation

## Overview
The **universal_printer** package provides a web‑first, cross‑platform printing solution for Flutter applications. It supports:
- Standard A4/Letter printers (PDF generation via `pdf` + `printing`).
- Thermal receipt printers on the web (roll‑size PDF 58 mm & 80 mm). 
- Native thermal printers (LAN TCP, Bluetooth/BLE, USB) using `esc_pos_utils_plus` & `flutter_thermal_printer` with automatic fallback to PDF when no raw device is paired.

### Conditional Export
```dart
export 'src/drivers/native_thermal_driver_stub.dart'
    if (dart.library.io) 'src/drivers/native_thermal_driver_io.dart';
```
All `dart:io` code lives in the `*_io.dart` file, ensuring web builds never import it.

## Usage Example
```dart
import 'package:universal_printer/universal_printer.dart';

final printer = UniversalPrinterService();
await printer.printDocument(
  PrintDocument(
    title: 'Invoice',
    items: [
      PrintLineItem(name: 'Consulting', qty: 1, unitPrice: 500.0),
    ],
    total: 500.0,
    qrData: 'https://example.com',
  ),
);
```
The service selects the appropriate driver based on `kIsWeb` and the stored `PrinterConfig`.

## Configuration UI
Add `PrinterSettingsSheet` anywhere in your UI:
```dart
showModalBottomSheet(
  context: context,
  builder: (_) => PrinterSettingsSheet(),
);
```
It lets users choose printer mode, connection method, IP/port, etc., persisting via `PrinterConfigRepository`.
