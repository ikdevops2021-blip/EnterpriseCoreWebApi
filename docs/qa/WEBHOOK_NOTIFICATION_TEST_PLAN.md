## Key Interactions to Verify
- Create a new webhook subscription with endpoint `https://example.com/webhook`, select events `token.issued` and `token.called`, save, and verify it appears in the list.
- Click "Test Webhook" to send a simulated mock event; verify the UI displays a green success status pill and exact response latency in milliseconds.
- Trigger a token state change (e.g., Call Next in Staff Console) and confirm the background dispatcher delivers the event asynchronously without blocking the teller UI.
- Inspect the Webhook Delivery Log drawer; verify that the generated `X-DQMS-Signature`, timestamp, payload, and response status code are accurately recorded.
- Toggle webhook status to inactive and verify subsequent queue events are not dispatched to that endpoint.

## Edge Cases
- **External Endpoint Offline / Timeout:**
  - Mock an external endpoint returning HTTP 500 or timing out after 10 seconds.
  - Verify delivery log marks status as `PendingRetry` with an exponential backoff time (e.g. +30s).
- **Circuit Breaker Activation:**
  - Simulate 10 consecutive connection failures to an endpoint.
  - Verify that the subscription is automatically paused (`CircuitBreakerUntil` set to UtcNow + 15m) and subsequent events are skipped.
- **HMAC Signature Tamper Protection:**
  - Verify that modifying a single character of the payload or secret key invalidates the computed HMAC-SHA256 signature.
- **High-Velocity Queue Bursts:**
  - Rapidly emit 100 queue events in under 2 seconds.
  - Verify that the bounded in-memory channel handles backpressure smoothly without dropped events or memory spikes.

## Critical Paths
- **Non-blocking Event Emission:**
  - Value: protects=StaffConsoleResponsiveness; fails_when=external webhook delays cause teller UI to lag; why_new=guarantees high-velocity queue dispatch is completely decoupled from 3rd-party network health.
- **Cryptographic Payload Signing:**
  - Value: protects=PayloadAuthenticity; fails_when=signatures are omitted or mismatched; why_new=allows partner hospitals and banks to securely verify DQMS event origin.
