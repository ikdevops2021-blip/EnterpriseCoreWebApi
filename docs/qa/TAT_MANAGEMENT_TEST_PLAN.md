## Affected Pages / Routes
- `/` (Command Center Dashboard Screen) — TAT Analytics Panel & Bottleneck Heatmap Grid
- `/api/v1/dqms/reports/summary` & `/api/v1/dqms/reports/tat-variance` — Backend TAT variance & dispersion endpoint
- `/api/v1/dqms/reports/bottleneck-heatmap` — Backend 2D matrix heatmap endpoint

## Key Interactions to Verify
- Select Date Range & Process Filter on Dashboard Screen and observe instant update of TAT Variance % and P95 statistics.
- Switch Heatmap dimension between "Hour × Day of Week", "Hour × Process", and "Hour × Counter".
- Hover / Tap on any cell in the 2D Bottleneck Heatmap Matrix to trigger the drill-down popover displaying token numbers, active operators, and wait time duration.

## Edge Cases
- Zero Tokens in selected time window (Heatmap must render complete empty grid with subtle neutral styling, not throw index out of bounds).
- Token in-flight (Token is active at a counter but not completed yet; system must compute live elapsed duration against SLA).
- TargetTAT = 0 or NULL (Division by zero guard must default safely without NaN or infinity).
- Database timeout on wide date range (Service should enforce 30-day max query range and return HTTP 400 with actionable error).
